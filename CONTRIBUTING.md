# Contributing

Thanks for sharing your work. Anyone can suggest a project, including their own.

## Add a project

1. Fork this repository and edit `README.md`.
2. Add one row to the section that fits best. Keep the table columns.
3. Open a pull request. One project per pull request.

Do not want to edit Markdown? Open a "Suggest a project" issue instead.

## What we list

- The project uses OpenArch, extends it, or connects something to it.
- The repository is public and has a README that says how to run it.
- The repository has a license. Partner products without public code go in "Partner solutions".
- The status is honest: Prototype, Working or Commercial.

## Writing the entry

- One or two short sentences. Say what it does, not how great it is.
- Link to the repository, not to a fork or a mirror.
- ASCII characters only.

## Help others find your work

Add the GitHub topic `openarch` to your repository (repository page, "About", gear icon).
